# NOVA TUNE — PROGRESS

## Статус
Все разделы интерфейса реализованы. EXE: `release/NOVA-TUNE.exe` (self-contained win-x64, single-file).
Каждый push собирается и проверяется на Windows (GitHub Actions, `.github/workflows/build.yml`):
юнит-тесты, `--self-test` (чтение реальных данных), `--screenshot` (обход всех страниц).

## Сделано
- Core (net10.0): бэкап/откат с журналом шагов и восстановлением после прерванной операции, модули оптимизации
  (игровой режим, Game DVR, план питания, HAGS), VDF/Steam/CS2, рекомендации CS2, автозагрузка (StartupApproved),
  очистка, оценка состояния, frametime-логи, ping, отчёты TXT/HTML, частота опроса мыши, статистика сессии. 80 тестов.
- Platform: реестр (64-бит), powrprof, повышение прав по белому списку (`--elevated-task`), WMI с таймаутами,
  характеристики, мониторинг (счётчики + LibreHardwareMonitor/PawnIO), D3DKMT (HAGS), диагностика, процессы.
- App (WPF): стеклянная дизайн-система (тёмная/светлая), RU/EN, 12 разделов, диалоги и уведомления в окне,
  один экземпляр, глобальная обработка исключений.

## Решения
- LHM 0.9.6 использует PawnIO (не WinRing0); температура CPU — только при установленном PawnIO и правах администратора.
- Раскрывающиеся блоки — во всплывающем окне с прокруткой, чтобы не сдвигать вёрстку.
- Параметры запуска Steam приложение не меняет (только показывает и копирует `+exec novatune`).

## Ограничения / не проверено
- Проверка выполнялась на Windows Server 2025 (виртуальная машина без Steam и дискретной GPU), не на Windows 10 22H2.
- Не проверены вживую: изменения с UAC, TRIM, точка восстановления, датчики CPU с PawnIO, ноутбук.
